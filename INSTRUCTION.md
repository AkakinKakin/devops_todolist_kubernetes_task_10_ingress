# Инструкция по проверке изменений

## 1. Запуск кластера Kubernetes с помощью kind

1. Убедитесь, что установлен [kind](https://kind.sigs.k8s.io/) и Docker.
2. В терминале перейдите в корень проекта.
3. Создайте кластер командой:
   ```
   kind create cluster --config cluster.yml
   ```

## 2. Деплой приложения и ingress-контроллера

1. Запустите скрипт для деплоя:
   ```
   ./bootstrap.sh
   ```
   > На Windows используйте `bash bootstrap.sh` или выполните скрипт в Git Bash/WSL.

## 3. Проверка ingress-ресурса

1. Убедитесь, что ingress создан:
   ```
   kubectl get ingress -n todoapp
   ```
   Должен появиться ресурс `my-ingress`.

2. Получите адрес ingress-контроллера:
   ```
   kubectl get svc -n ingress-nginx
   ```
   Найдите внешний IP или порт (обычно это NodePort, если кластер локальный).

3. Проверьте доступность приложения через ingress:
   - Откройте браузер или используйте curl:
     ```
     curl http://<INGRESS_IP>:<PORT>/todoapp/
     ```
   - Должен открыться интерфейс или ответ приложения.

## 4. Проверка маршрутизации

- Убедитесь, что путь `/todoapp/` корректно проксируется на сервис `todoapp-service` на порту 80.
- Проверьте, что другие пути, например `/todoapp/api`, также работают.

---

**Примечание:**  
Если возникнут проблемы с доступом, проверьте логи ingress-контроллера и убедитесь, что все поды в namespace `todoapp` работают (`kubectl get pods -n todoapp`).
